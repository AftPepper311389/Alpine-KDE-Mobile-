# Alpine KDE Mobile

An experimental single-APK Android launcher/runtime project targeting Alpine Linux with KDE Plasma.

## Target

- Alpine Linux stable (initial baseline: 3.24.x)
- KDE Plasma desktop
- Android arm64-v8a
- No root; ADB-assisted setup where supported
- GitHub Actions-only builds

## Status

This repository is being initialized. GPU acceleration, unrooted display integration, ADB setup, and full Alpine/Plasma boot are not yet implemented or validated. A successful Android APK build must not be interpreted as proof that the Linux desktop or hardware acceleration works.

## Build

The Android project and CI workflow will be added incrementally. See GitHub Actions for build results once the workflow is present.
